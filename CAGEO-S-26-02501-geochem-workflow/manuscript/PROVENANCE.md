# Provenance

This repository was reorganized from the user-provided archive `geochem.workflow.zip` on 2026-11-07. The original archive contained the Python package modules, synthetic data, a workflow image, a synthetic-data generator and unit tests. Build artifacts and generated package metadata were removed from the repository root; the source modules and tests were preserved.

The repository adds packaging metadata, a demonstration YAML configuration, documentation, a Mermaid workflow source, a citation file and a Code Availability statement. No manuscript-specific raw geochemical dataset has been copied into the repository.
