# Results directory

`results/demo/` contains the output of the complete end-to-end run using the included synthetic dataset and `configs/demo.yaml`. These files verify that SGS, fractal analysis, RF/MLP spatial validation, SHAP aggregation, robustness classification and the correlation network execute successfully.

The synthetic outputs are software-validation artifacts only. They are not the results of the Jbel Saghro/Tiouit–Ikneewin study and must not be used in the manuscript as geological evidence.
